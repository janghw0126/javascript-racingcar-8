# javascript-racingcar-precourse

---

## 기능 요구 사항

초간단 **자동차 경주 게임**을 구현한다.

- [x] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- [x] 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 함께 출력한다.
    - [x] 자동차 이름은 쉼표(,)를 기준으로 구분하며, 이름은 5자 이하만 가능하다.
- [x] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
    - [x] 전진 조건:  0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우 전진한다.
- [x] 경주가 완료되면 우승자(복수 가능)를 출력한다.
    - [x] 우승자가 여러 명일 경우 쉼표(,)로 구분한다.
- [x] 사용자가 잘못된 값을 입력할 경우 [ERROR]로 시작하는 에러 메시지를 출력하고, 예외를 발생시킨 후 애플리케이션은 종료된다.

## 기능 구현 목록

이번 미션에서는 정상적으로 동작하는 프로그램을 우선 구현한 뒤, 점차 예외 처리 등 구조를 개선하자는 목표로 접근했다. 이를 위해 먼저 핵심 로직이 돌아가도록 작은 기능부터 구현하고, 이후 각 기능별 입력 검증과 예외 처리를 추가하는 순서로 진행했다.

### ✅ 입력 관련

자동차의 경주 게임 시작은 자동차의 이름을 입력받는 것으로부터 시작된다. 따라서 입력값이 올바르지 않으면 이후 모든 로직이 깨질 수 있으므로, 초반에 입력 검증 로직을 가장 먼저 설계했다.

- [x] 자동차 이름 입력
- [x] 자동차 이름 검증(validateCarName)

### ✅ 게임 로직

경주 로직은 입력된 자동차들이 동일한 규칙(무작위 값에 따라 전진 여부를 판단)으로 반복 경주를 진행한다는 로직을 중심으로 설계했다.
-> 이를 위해 자동차별 상태를 한눈에 관리할 수 있도록 객체를 사용했으며, 시도 횟수만큼 반복하면서 매 라운드마다 자동차의 전진 여부를 판단하도록 구성하였다.

- [x] 자동차 이동 상태 객체(carStates) 선언
- [x] 시도 횟수 입력 및 검증(validateRaceCount)
- [x] 시도 횟수만큼 반복하며 경주 게임 진행
    - [x] 자동차 전진 여부 판단(checkCarMovement)
        - [x] 0~9 사이 무작위 값 생성
        - [x] 무작위 값 4 이상일 경우, 전진(moveCar) 실행
        - [x] 무작위 값 4 미만일 경우, 정지(아무 동작 X)
    - [x] 전진 함수(moveCar)
        - [x] 전진 횟수 1 증가
    - [x] 현재 라운드별 자동차 이동상태 출력 함수(printCarState)

### ✅ 결과 처리

게임 종료 후에는 각 자동차의 이동거리인 전진 횟수를 비교하여 우승자를 판별했다. 최댓값을 구해 하나 이상의 우승자를 반환하며, 공동 우승의 경우에도 함께 출력할 수 있도록 설계했다.

- [x] 우승자 출력
    - [x] 우승자 판단 함수(determineWinner)
        - [x] 각 자동차의 이동 거리 횟수 비교
        - [x] 최댓값을 기준으로 우승자 반환
        - [x] 우승자가 여러 명인 경우, 공동 우승자로 출력

### ✅예외 처리

프로그램이 예기치 않게 종료되거나 잘못된 입력으로 오류가 발생하지 않도록, 다양한 예외 상황을 고려했다. 입력 단계에서 발생할 수 있는 모든 오류를 미리 설계하고 기본적인 기능을 먼저 구현한 뒤, 에러 메시지를 출력하도록 예외 처리를 추가하였다.

- [x] 자동차 이름 검증(validateCarName)
    - [x] 입력값 사이에 공백이 있을 경우
    - [x] 쉼표가 아닌 다른 구분 기호 사용했을 경우 확인
    - [x] 자동차의 이름을 하나만 입력한 경우 확인
    - [x] 자동차 이름 입력이 비어있을 경우 확인
    - [x] 자동차 이름이 5자 초과인 경우 확인
- [x] 시도 횟수 입력 및 검증(validateRaceCount)
    - [x] 시도 횟수 입력이 비어있을 경우
    - [x] 숫자가 아닌 문자를 입력 받을 경우
    - [x] 0 이하의 숫자를 입력했을 경우

## 프로그래밍 흐름

1. 자동차의 이름을 입력받는다.

2. 자동차의 이름을 검증하는 함수를 실행한다.
    2-1. 자동차 이름 구분자에 대한 예외 처리를 한다.
    - 입력값 사이에 공백이 있을 경우 [ERROR] 처리
    - 쉼표 이외의 다른 구분 기호를 사용했을 경우 [ERROR] 처리

    2-2. 쉼표를 기준으로 입력 문자열(자동차 이름)을 분리한다.

    2-3. 자동차 이름 길이에 대한 예외 처리를 한다.
    - 자동차의 이름을 하나만 입력한 경우 [ERROR] 처리
    - 자동차의 이름이 비어있는 경우 [ERROR] 처리
    - 자동차의 이름이 5자 초과인 경우 [ERROR] 처리

    2-4. 검증 완료 후, 자동차의 이름을 반환한다.

3. 자동차의 이동 상태 객체를 선언한다.

4. 시도 횟수를 입력받는다.
    4-1. 시도 횟수에 대한 예외 처리를 한다.
    - 입력이 비어있을 경우 [ERROR] 처리
    - 숫자가 아닌 문자를 입력한 경우 [ERROR] 처리
    - 0 이하의 숫자를 입력했을 경우 [ERROR] 처리

5. 입력 받은 시도 횟수만큼 경주 게임을 실행한다.
    5-1. 각각의 자동차에 전진 여부를 판단하는 함수를 실행한다.
    - 0과 9 사이의 무작위 값을 생성한다.
    - 무작위 값이 4 이상일 경우, 전진 함수를 실행한다.
    - 무작위 값이 4 미만일 경우, 정지한다.(아무 동작 X)

    5-2. 자동차 이동을 처리하는 함수를 실행한다.(전진하는 경우)
    - 전진하는 자동차의 이동 상태 배열에 전진 횟수를 1 증가 시킨다.

    5-3. 현재 라운드별 자동차 이동상태를 출력하는 함수를 실행하고 줄바꿈을 실행한다.

6. 우승자를 판별하고 출력한다.
    6-1. 우승자 계산
    - 자동차들의 이동 거리 중 최댓값을 구한 후, 그 거리와 같은 값을 가진 자동차 이름들을 판별하여 공동 우승자를 배열로 반환한다.

## 배운 점

1. forEach, for…of, for…in의 차이와 올바른 사용 맥락
- carNames.forEach((name) => { carStates[name] = 0; }) 처럼 배열 순회에 forEach를 사용하며 콜백 기반의 반복문 패턴을 익혔다.
- for…of는 배열의 값(value) 순회하고, for…in은 객체의 키(key) 순회에 적합하다는 것을 이해했다. 이를 통해 상황에 따라 올바른 문법을 선택할 수 있게 되었다.

2. 클래스 내부 메서드 정의와 this 활용
- function 키워드 없이 validateCarName() {} 형태로 메서드를 정의할 수 있다는 것을 익혔다.
- 클래스 내부에서 this를 이용해 다른 함수를 호출하는 방법을 익혔다.

3. 객체를 배열로 변환하여 필요한 값(키, 값)만 처리하는 방법을 배웠다.

4. join() 메서드를 통해 우승자 배열을 문자열로 변환하여 출력했다.

5. Jest를 이용하여 정상 입력과 예외 케이스를 분리하고, test.each()를 홣용해 파라미터화 테스트를 작성하였다.
- 이를 통해 테스트 코드를 더 가독성있게 작성할 수 있었고, 프로그램의 안정성을 확인할 수 있었다.
