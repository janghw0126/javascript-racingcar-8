# javascript-racingcar-precourse
## 기능 요구 사항

초간단 **자동차 경주 게임**을 구현한다.

- [ ] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- [ ] 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 함께 출력한다.
    - [ ] 자동차 이름은 쉼표(,)를 기준으로 구분하며, 이름은 5자 이하만 가능하다.
- [ ] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
    - [ ] 전진 조건:  0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우 전진한다.
- [ ] 경주가 완료되면 우승자(복수 가능)를 출력한다.
    - [ ] 우승자가 여러 명일 경우 쉼표(,)로 구분한다.
- [ ] 사용자가 잘못된 값을 입력할 경우 [ERROR]로 시작하는 에러 메시지를 출력하고, 예외를 발생시킨 후 애플리케이션은 종료된다.


## 과제 진행 요구 사항

- [ ] Node.js 버전은 22.19.0 이상인지 확인한다.
- [ ] 기능 목록 단위로 커밋을 진행한다.
- [ ] 요구 사항에 명시된 출력 형식을 따라야 한다.
```javascript
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```
- [ ] 모든 테스트가 성공적으로 실행되는지 확인한다.
- [ ] 프로그램 실행의 시작점은 App.js의 run()이다.
- [ ] package.json 파일은 수정할 수 없으며, 외부 라이브러리는 사용하지 않는다.
- [ ] 프로그램 종료 시 process.exit()를 호출하지 않는다.
- [ ] 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다.
- [ ] 자바스크립트 코드 컨벤션을 지키면서 프로그래밍한다.
- [ ] 인텐트 깊이를 2 이하로 유지한다.
- [ ] 3항 연산자를 쓰지 않는다.
- [ ] 함수나 메서드가 한 가지 일만 하도록 최대한 작게 만든다.
- [ ] Jest를 이용하여 기능 테스트를 수행한다.
- [ ] @woowacourse/mission-utils에서 제공하는 Random 및 Console API를 사용하여 구현한다,
    - [ ] Random.pickNumberInRange()
    - [ ] Console.readLineAsync(), Console.print()

## 기능 구현 목록

### 입력 관련
- [ ] 자동차 이름 입력
- [ ] 자동차 이름 검증(validateCarName)

### 게임 로직
- [ ] 자동차 이동 상태 배열(carStates) 선언
- [ ] 시도 횟수 입력 및 검증(validateraceCount)
- [ ] 시도 횟수만큼 반복하며 게임 진행
    - [ ] 자동차 전진 여부 판단(checkCarMovement)
        - [ ] 0~9 사이 무작위 값 생성
        - [ ] 무작위 값 4 이상일 경우, 전진(moveCar) 실행
        - [ ] 무작위 값 4 미만일 경우, 정지(아무 동작 X)
    - [ ] 전진 함수(moveCar)
        - [ ] 자동차의 이동 상태 배열에 '-' 추가
    - [ ] 자동차 이동 진행 결과 출력(printCarState)

### 결과 처리
- [ ] 우승자 출력
    - [ ] 우승자 판단 함수(determineWinner)
        - [ ] 각 자동차의 이동 거리('-') 비교
        - [ ] 최댓값을 기준으로 우승자 반환
        - [ ] 우승자가 여러 명인 경우, 공동 우승자로 출력

### 예외 처리
- [ ] 자동차 이름 검증(validateCarName)
    - [ ] 쉼표 구분자 확인
    - [ ] 쉼표가 아닌 다른 구분 기호 사용했을 경우 확인
    - [ ] 쉼표 구분자가 누락된 경우 확인
    - [ ] 입력값 사이에 공백이 있을 경우
    - [ ] 쉼표를 기준으로 이름 분리 
    - [ ] 자동차 이름 입력이 비어있을 경우 확인
    - [ ] 자동차의 이름을 하나만 입력한 경우 확인
    - [ ] 자동차 이름이 5자 초과인 경우 확인
    - [ ] 검증 후, 자동차의 이름 반환
- [ ] 시도 횟수 입력 및 검증(validateRaceCount)
    - [ ] 숫자가 아닌 문자를 입력 받을 경우
    - [ ] 시도 횟수 입력이 비어있을 경우
    - [ ] 0 이하의 숫자를 입력했을 경우

## 프로그래밍 흐름

1. 자동차의 이름을 입력받는다.

2. 자동차의 이름을 검증하는 함수를 실행한다.
    2-1. 자동차 이름 구분자에 대한 예외 처리를 한다.
    - 쉼표 이외의 다른 구분 기호를 사용했을 경우 [ERROR] 처리
    - 쉼표 구분자가 누락된 경우 [ERROR] 처리
    - 입력값 사이에 공백이 있을 경우 [ERROR] 처리

    2-2. 쉼표를 기준으로 입력 문자열(자동차 이름)을 분리한다.

    2-3. 자동차 이름 길이에 대한 예외 처리를 한다.
    - 자동차의 이름을 하나만 입력한 경우 [ERROR] 처리
    - 자동차의 이름이 비어있는 경우 [ERROR] 처리
    - 자동차의 이름이 5자 초과인 경우 [ERROR] 처리

    2-4. 검증 완료 후, 자동차의 이름 배열을 반환한다.

3. 자동차의 이동 상태 배열을 선언한다.

4. 시도 횟수를 입력받는다.
    4-1. 시도 횟수에 대한 예외 처리를 한다.
    - 숫자가 아닌 문자를 입력한 경우
    - 입력이 비어있을 경우
    - 0 이하의 숫자를 입력했을 경우

5. 입력 받은 시도 횟수만큼 반복 실행한다.
    5-1. 각각의 자동차에 전진 여부를 판단하는 함수를 실행한다.
    - 0과 9 사이의 무작위 값을 생성한다.
    - 무작위 값이 4 이상일 경우, 전진 함수를 실행한다.
    - 무작위 값이 4 미만일 경우, 정지한다.(아무 동작 X)

    5-2. 자동차 이동을 처리하는 함수를 실행한다.(전진하는 경우)
    - 전진하는 자동차의 이동 상태 배열에 '-'를 추가한다.

    5-3. 각 자동차의 현재 진행 상황을 출력하는 함수를 실행하고 줄바꿈을 실행한다.

6. 우승자를 판별하고 출력한다.
    6-1. 우승자 계산
    - 각 자동차의 이동 거리('-' 개수) 를 계산한다.
    - 가장 많은 이동 거리를 가진 우승자를 우승자로 반환한다.
    
    6-2. 공동 우승 처리
    - 최대 이동 거리가 동일한 경우, 공동 우승자로 반환한다.
